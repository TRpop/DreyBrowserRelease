## 1. 설정 왼쪽 목록 스크롤이 튕기던 문제
- 설정 왼쪽 목록을 마우스 휠·터치패드·키보드로 직접 스크롤하면, 선택된 항목이 화면 밖으로 나가는 순간 목록이 그 항목 쪽으로 되돌아갔습니다.
  - 첫 항목이 선택돼 있으면 아래로 내려가지 않았습니다.
  - 마지막 항목이 선택돼 있으면 위로 올라가지 않았습니다.
- 이제 직접 옮긴 목록 위치를 그대로 둡니다. 목록이 선택 항목 쪽으로 저절로 옮겨 가는 것은 다음 경우뿐입니다.
  - 오른쪽 본문을 스크롤해 선택이 다른 항목으로 바뀔 때
  - 목록 항목을 누르거나 주소·기능 안내로 특정 칸을 열 때
- 오른쪽 본문 스크롤, 스크롤에 따라 바뀌는 목록 선택 표시, 칸 바로 열기(주소의 `#칸`)는 그대로입니다.
- 확인 방법: 설정을 열고 창을 세로로 줄여 왼쪽 목록이 넘치게 합니다.
  1. 본문을 맨 위에 둔 채(첫 항목 선택) 왼쪽 목록 위에서 휠을 아래로 굴려, 목록이 내려간 채 머무는지 봅니다.
  2. 본문을 맨 아래에 둔 채(마지막 항목 선택) 휠을 위로 굴려, 목록이 올라간 채 머무는지 봅니다.

## 2. 첫 공개 판·업데이트
- 1.0.0 은 공개 다운로드 저장소(https://github.com/TRpop/DreyBrowserRelease)의 Release 로 처음 내는 판입니다. 설치 파일과 함께 업데이트용 파일도 같은 Release 에 올립니다.
- 0.29.4 를 쓰시는 경우, 앱에 이미 이 저장소가 업데이트 주소로 들어 있습니다. 1.0.0 이 올라가면 앱이 업데이트를 찾을 수 있습니다.
  - 자동 확인('시작할 때 자동으로 확인'이 켜져 있을 때): 앱을 켜고 30초 뒤에 확인합니다. 확인에 성공했다면 24시간 안에는 다시 확인하지 않습니다. 켜 둔 채로 주기적으로 다시 확인하지는 않습니다.
  - 바로 확인하려면 설정 > 정보의 업데이트 확인을 누르세요.
- 1.0.0 부터 설치한 경우에도 같은 주소로 다음 판을 확인합니다.
- 실제 0.29.4 → 1.0.0 내장 업데이트를 어디까지 확인했는지는 이 안내가 아니라 검증·발행 결과에 따로 적습니다.

## 그대로인 것·한계
- 설치 파일은 서명하지 않았습니다.
- 설정 목록 수정은 Windows Sandbox 에서 실제 휠·작은 휠 연속 입력·방향키로 확인했습니다. 실제 정밀 터치패드는 작은 휠 연속 입력으로 흉내 내 확인했고, 사용자 PC 의 터치패드로는 확인하지 않았습니다.
