# Drey Browser 1.0.1

## 업데이트 안내 개선

- 새 버전 다운로드를 시작하면 진행률과 취소·자세히 안내를 표시합니다.
- 다운로드가 끝나면 '지금 재시작해 업데이트'와 '나중에'를 선택할 수 있습니다.
- 나중에를 선택하거나 완료 안내를 닫으면 받은 파일은 유지하고, 브라우저 종료 시 적용을 예약합니다. 진행 중인 작업 등 기존 보호 조건은 유지됩니다.
- 다운로드 실패 시 원인 안내와 다시 시도 버튼을 표시합니다. 취소를 완료로 알리지 않습니다.
- 재시작이 현재 작업 때문에 막히면 이유와 다음 행동을 표시합니다.

## 확인 시 참고

이 안내는1.0.1에 들어 있습니다. 기존1.0.0에서 이번 버전을 받는 동안에는 기존 안내 방식이 유지됩니다.1.0.1 설치 후 이후 업데이트부터 새 안내가 적용됩니다.

## 검증

설치 업데이트·자료 보존32/32, 새 안내 한국어14/14·영어14/14 통과. 기존 미연결 빌드를 전제로 한 시험3건은 공개 서버 연결과 맞지 않아 근거를 남기고 예외로 승인했습니다. 실제 네트워크 진행률과 실제 자동 적용은 미확인입니다. 자세한 결과는 검증 보고서를 참고하세요. 공개1.0.0 파일은 교체하지 않았고1.0.1 공개 발행은 하지 않았습니다.
