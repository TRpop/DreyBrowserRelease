Drey Browser
EnglishREADME

한 가지 일을 한곳에 — 탭, 문서, 폴더, AI.

Drey Browser 는 일을 위한 Windows 브라우저입니다. 한 가지 일에 필요한 웹 페이지·문서·폴더·AI 도움을 세로 탭 목록의 그룹으로 함께 두고, 페이지 영역은 넓게 씁니다.

  • 바로 시작 — Drey 계정·로그인·동기화가 없습니다. 웹사이트와 AI 서비스는 각자의 로그인을 씁니다.
  • 업무를 따로 — 개인 브라우저와 함께 씁니다.
  • 자료는 이 PC 에 — Windows 사용자 프로필에 저장됩니다.

제품 소개 페이지입니다. 그림은 설명용으로 그린 예시(그림 속 글은 짧은 영어)이며 실제 화면을 찍은 것이 아니고, 이 페이지는 앱을 조작하지 않습니다. Microsoft Edge WebView2(Chromium) 엔진을 씁니다.

세로 탭, 넓은 페이지

탭은 왼쪽 목록에 있습니다. 가로 탭 줄이 없어 페이지가 창 높이를 다 씁니다.

  1. 고정 목록 — 이름과 그룹이 늘 보입니다. 넓은 모니터에 알맞습니다.
  2. 아이콘 줄 — 아이콘으로 접었다가 이름이 필요할 때 펼칩니다.
  3. 숨김 — 버튼·왼쪽 가장자리·단축키로 페이지 위에 엽니다. 좁거나 세로로 긴 창에 알맞습니다.

일마다 그룹, 옆에는 사이드뷰

예 — 거래처 검토: 포털·계약서·프로젝트 폴더를 한 그룹에 둡니다.

  1. 그룹 — 이름·색·설명을 붙이고, 안 쓰는 그룹은 접어 둡니다.
  2. 넓은 페이지 — 지금 페이지가 나머지 창을 씁니다.
  3. 사이드뷰 — 옆에 두 번째 페이지 — 포털을 보면서 Markdown 메모를 엽니다.

끝난 그룹은 보관하거나 내보내기

일을 잃지 않고 닫거나, 파일로 옮깁니다.

  1. 그룹 메뉴 — 그룹 보관 또는 파일로 내보내기.
  2. 보관함 — 탭은 닫히고, 나중에 그룹째 다시 꺼냅니다.
  3. .dreygroup 파일 — 그룹을 파일로 — 폴더 안 파일과 웹사이트 비밀번호는 들어가지 않습니다.
  4. 나중에 불러오기 — 이 PC 나 다른 PC 에서 다시 엽니다.

탐색기 데스크톱

파일 탐색기 폴더 여러 개를 탭 하나에, 업무 그룹과 함께.

  1. 폴더 창 — 계약·공유·다운로드·보고서 폴더를 나란히.
  2. 그룹의 일부 — "Project folders" 가 Vendor review 그룹에 있습니다.
  3. 배치 저장 — 같은 모양으로 다시 열립니다. 폴더를 복사하지 않고 권한도 바뀌지 않습니다.

AI, 네 가지 방법

기능마다 하는 일이 다릅니다. AI Agent 와 질문 창은 Claude Code 또는 Codex 를 설치하고 각자 계정으로 로그인해야 합니다.

  1. AI Agent — 프로젝트 폴더에서 일합니다. 대화하고, 파일 변경을 검토하고, 실행을 승인·거절합니다.
  2. 이 페이지에 질문 (✦) — 페이지 글과 질문을 이 PC 의 Claude Code·Codex 로 보내고, 답이 페이지 옆에 나옵니다.
  3. 사이드뷰 웹 챗봇 — ChatGPT·Copilot 의 일반 웹 페이지입니다. 페이지를 스스로 읽지 않으니 Markdown 으로 복사해 붙여 넣습니다.
  4. MCP (Model Context Protocol, 외부 AI 앱 연결) — 바깥 AI 앱이 탭을 읽고, 내가 맡긴 그룹 안에서만 조작합니다. ⏸ 로 되찾습니다.

문서와 확장

문서를 탭에서 열고 브라우저를 넓힙니다. 간단한 수정용 텍스트/코드 편집기와 Hex 편집기도 있습니다.

  1. Markdown — 수식·다이어그램·차트와 함께 읽고 고칩니다.
  2. 한글 (HWP/HWPX) — 한글 문서를 탭에서 열고 고칩니다.
  3. 캡처 — 영역·요소·보이는 화면·페이지 전체 — 복사하거나 저장합니다.
  4. 유저스크립트 — Tampermonkey 형식 스크립트와 백업 가져오기. Tampermonkey 를 완전히 대신하지는 않으며 내장 화면에서는 실행되지 않습니다.
  5. 플러그인 — 켜고 끄기, 파일 설치, 제작 문서로 직접 만들기.

코드 서명하지 않은 설치 파일이라 Windows 가 경고를 보일 수 있습니다. 본체 소스는 공개하지 않으며, 오픈소스 고지는 앱과 THIRD-PARTY-NOTICES.txt 에 있습니다. 내장 에이전트 스킬은 MIT 라이선스이며 소스 저장소는 TRpop/DreySkills 입니다.
